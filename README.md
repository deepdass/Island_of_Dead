# Island of Dead
Escape the infected island as a chibi character with his trusted buddy, ghosty, while fighting through the dead and exploring the island

It is a 2d platformer made using free assets. Also the first game I made without following a tutorial, where I tried to figure things out on my own, which helped me learn a lot more about how things actually work

## Why 
I loved making games in Python, but those were basic but fun nevertheless. Then I got to know about game engines and started game dev with Unity, as it had many more tutorials on this stuff
<br>Well I didn’t plan much before making this game, I just added what seemed fun to me
